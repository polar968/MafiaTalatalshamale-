# Mafia Cafe Talat-alshamale
نسخة أولية Prototype.
- تسجيل دخول بالاسم ورقم الهاتف.
- مساعد توزيع كروت ورقية بناءً على الكروت المتوفرة.
- واجهات أولية للجلسات والشات والقوانين والسجل والأرباح.

ملاحظة: هذه النسخة Front-end تجريبية. تسجيل الدخول والشات والبيانات المشتركة بين الأجهزة تحتاج Backend وقاعدة بيانات في المرحلة التالية.
