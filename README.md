# Mafia Cafe Talat-alshamale v2
تعديل أولي على النسخة الحالية.

## التعديلات
- تسجيل اللاعب بالاسم + رقم الهاتف.
- إلزام اللاعب باختيار: شباب أو فتيات.
- إظهار شات الفئة المختارة فقط في واجهة اللاعب.
- إضافة دخول إدارة منفصل.
- إضافة لوحة إدارة.
- إخفاء عناصر الإدارة عن اللاعبين.
- شات منفصل محلياً لكل فئة.

## مهم جداً
هذه النسخة ما زالت Front-end محلية. كلمة مرور/بيانات الإدارة الموجودة في JavaScript يمكن كشفها من ملفات الموقع، وlocalStorage لا يوفر خصوصية حقيقية بين الأجهزة.

للحصول على النسخة النهائية الآمنة:
1. Backend وقاعدة بيانات.
2. حسابات وصلاحيات حقيقية.
3. صلاحية player_male / player_female / admin على الخادم.
4. كل رسالة شات تحفظ في قاعدة البيانات مع room_id مناسب.
5. الخادم هو الذي يمنع لاعب الشباب من قراءة رسائل الفتيات والعكس.
6. بيانات الهاتف لا تظهر في الشات؛ يظهر اسم العرض فقط.

لا تستخدم بيانات الدخول الموجودة في هذه النسخة كحماية أمنية حقيقية.
